# Quillnote CLI

Quillnote turns a folder of Markdown notes into a searchable static site.

## Requirements

| Requirement | Minimum version | Notes |
|---|---|---|
| Node.js | 20.0 | LTS recommended |
| Git | 2.30 | Needed for `quill deploy` |
| Disk space | 200 MB | For the search index |

## Installation

```sh
npm install -g quillnote
quill init ./notes   # creates quill.config.json
quill build
quill serve          # http://localhost:4000
```

## Configuration

Set these in `quill.config.json`:

- `title`: site title shown in the header.
- `baseUrl`: URL where the site will be hosted. Must end with a slash.
- `exclude`: glob patterns for notes that should not be published.

> **Warning:** Notes are published as-is. Anything not matched by `exclude` will be public after `quill deploy`, including notes that contain private information.

## Troubleshooting

- **`quill: command not found`**: The global install did not complete, or npm's global bin is not on your `PATH`. Reinstall and check `PATH`.
- **`Missing quill.config.json`**: Run `quill init` in your notes folder.
- **Search returns no results**: Delete the `.quill/` cache folder and run `quill build` again.
