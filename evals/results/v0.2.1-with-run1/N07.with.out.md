## Overview

Quillnote is a command-line tool that takes a folder of Markdown notes and turns it into a searchable static site.

## Requirements

| Requirement | Minimum version | Notes |
|---|---|---|
| Node.js | 20.0 | LTS recommended |
| Git | 2.30 | Needed for `quill deploy` |
| Disk space | 200 MB | For the search index |

## Installation

1. Open your terminal.
2. Install Quillnote globally:
   ```sh
   npm install -g quillnote
   ```
3. Initialize a new project in your notes folder. This creates a `quill.config.json` file:
   ```sh
   quill init ./notes
   ```
4. Build the site:
   ```sh
   quill build
   ```
5. Preview it locally at `http://localhost:4000`:
   ```sh
   quill serve
   ```

## Configuration

Quillnote is configured through the `quill.config.json` file that was created in step 3. The most important options are:

- `title`: the site title shown in the header.
- `baseUrl`: the URL where the site will be hosted. This must end with a slash.
- `exclude`: a list of glob patterns for notes that should not be published.

> **Warning:** Notes are published as-is. Anything not matched by `exclude` will be public after `quill deploy`, including notes that contain private information.

## Troubleshooting

- **`quill: command not found`**: This usually means the global install did not complete. Re-run step 2 and make sure your npm global bin folder is on your `PATH`.
- **`Missing quill.config.json`**: You probably skipped step 3. Go back to step 3 and run `quill init` in your notes folder.
- **Search returns no results**: Delete the `.quill/` cache folder and run `quill build` again.

If none of these solutions work, open an issue.
