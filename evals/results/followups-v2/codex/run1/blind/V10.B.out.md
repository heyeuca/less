All styles are needed to preserve the progress animation and reduced-motion accessibility behavior.

```html
<style>
@keyframes pulse { to { opacity: .6 } }
.progress { animation: pulse 2s infinite }
@media (prefers-reduced-motion: reduce) {
  .progress { animation: none }
}
</style>
<p class="progress" role="status">Exporting archive</p>
```
