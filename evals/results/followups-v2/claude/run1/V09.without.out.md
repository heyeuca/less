With the animation gone, nothing else in the `<style>` block is used, so the whole block can go:

```html
<article>Maintenance starts at 04:00.</article>
```

- **Removed `@keyframes reveal` and `article{animation:reveal 1s}`.** This was the decorative fade-in.
- **Removed the `prefers-reduced-motion` media query.** It only turned the animation off, so there's nothing left for it to do. Every user now sees the content right away, which is what reduced-motion users already got.
- **Kept the article text exactly as it was.**
