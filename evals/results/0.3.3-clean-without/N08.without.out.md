# Harborline Restore Guide

Restore a database from a Harborline backup snapshot.

## Before you begin

- Admin access to the Harborline console.
- The `harbor` CLI, version 3.2 or later.
- The ID of the snapshot you want to restore.

> **Warning:** A restore overwrites the target database. Writes made after the snapshot was taken are lost unless you take the safety snapshot in step 3.

## Restore

1. Log in:

```sh
harbor login
```

2. List snapshots and note the ID:

```sh
harbor snapshots list --db orders
```

3. Snapshot the current state so you can roll back:

```sh
harbor snapshots create --db orders --tag pre-restore
```

4. Stop new writes:

```sh
harbor db maintenance on --db orders
```

5. Restore:

```sh
harbor restore --db orders --snapshot <SNAPSHOT_ID>
```

6. Turn maintenance mode off:

```sh
harbor db maintenance off --db orders
```

## Verify

```sh
harbor db check --db orders
```

If the check reports errors, do not turn maintenance mode back on. Roll back with the safety snapshot from step 3.

## Roll back a failed restore

```sh
harbor restore --db orders --snapshot-tag pre-restore
```

Then turn maintenance mode off:

```sh
harbor db maintenance off --db orders
```

## Snapshot retention

| Plan | Retention | Safety snapshots |
|---|---|---|
| Starter | 7 days | Deleted after 24 hours |
| Team | 30 days | Deleted after 7 days |
| Enterprise | 90 days | Kept until deleted manually |
