Open-source agent skill

github.com/heyeuca/less

install

01

Where it applies

One standard, in writing, code, and UI.

01

Writing

Keep the sentence that makes the point. Cut the warm-up and the ending that repeats it.

02

Code

Keep the code that does the job. Cut the wrapper that nothing calls and the comment that repeats the line.

03

UI

Keep the control the task needs. Cut decoration and a second control that does not change the outcome.
